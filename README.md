☕ Brew & Bite Café

Brew & Bite Café is a responsive, multi-page cafe website developed as part of a Web Technology Continuous Assessment assignment.

The website showcases a cafe’s menu, food gallery, and table booking interface using HTML5, CSS3, and JavaScript.

 Features

*  Home page with cafe introduction and highlights
*  Menu page with food items and prices
*  Gallery page featuring cafe and food images
*  Contact and table booking form
*  Navigation bar connecting all pages
*  Dark and light mode
*  Responsive design for mobile, tablet, and desktop
*  Form validation
*  Embedded Google Maps
*  Modern cafe-inspired design

 Technologies Used

* HTML5
* CSS3
* JavaScript
* Flexbox and CSS Grid
* Local Storage
* Google Maps Embed

 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using the Live Server extension.
4. Explore the website in your browser.

🎯 Project Objective

The objective of this project is to demonstrate practical knowledge of semantic HTML5, CSS styling, responsive web design, JavaScript interactions, HTML tables, forms, and multimedia integration.
